# survey-tally

엑셀에서 설문 응답을 머리글 줄까지 복사해 붙여넣으면 문항별 결과 표를 보여 주는 한 파일짜리 웹 페이지(`index.html`)입니다.

- 외부 라이브러리, 외부 글꼴, 분석 도구를 쓰지 않습니다.
- 붙여넣은 데이터는 브라우저 안에서만 계산합니다. 어디로도 보내거나 저장하지 않습니다.

## 쓰는 법

`index.html`을 브라우저로 열거나 GitHub Pages로 배포해 엽니다. 엑셀에서 머리글 줄을 포함해 범위를 복사하고 입력칸에 붙여넣으면 바로 집계됩니다.

## 집계 규칙

- 첫 줄은 머리글, 첫 열(응답번호)은 집계하지 않습니다.
- 앞뒤 공백을 지운 값이 `1`~`5`이면 **유효**, 비었거나 공백만 있으면 **빈 응답**, 그 밖의 값은 **제외**입니다.
- 칸 수가 머리글보다 모자란 줄은 모자란 칸을 빈 응답으로 셉니다.
- **평균**은 유효 응답의 합 ÷ 유효 응답 수를 소수 셋째 자리에서 반올림해 둘째 자리까지 씁니다. 유효가 0이면 `-`입니다.

결과 표 아래에는 문항별 평균을 0~5점 가로 막대그래프로도 보여 줍니다. 막대 길이는 표에 보이는 평균과 같은 값이고, 유효 응답이 없는 문항은 막대 없이 `-`로 표시합니다.

자세한 결정 사항은 [docs/PLAN.md](docs/PLAN.md)에 있습니다.

## 시험

Node.js 22 이상이 필요하며 설치할 패키지는 없습니다.

```bash
npm test
```

- `test/tally.test.js`: `index.html`의 `<script id="tally-core">` 블록을 꺼내 집계 계산을 시험합니다.
- `test/static.test.js`: 외부 자원, 네트워크·저장 API가 없는지, CSP와 `.nojekyll`이 있는지 검사합니다.
